# Changelog

## 1.1.0

- `ShowColumn` / `ShowInventoryColumn`: hide the side column while playing, or only while inventory, chest or crafting is open; Alt+H keeps working (#2).
- `OverlayColumns` (1-4) and `OverlaySize` for the Alt+H list (#2).
- `OverlayFontSize` is now described as what it is: the list's font size, shrunk only when it doesn't fit.
